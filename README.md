# Replication files: *Synthetic Control: An Exact Geometric Formulation*

Alberto Abadie and Yucheng Shang

Version: **1.0.0**.

Original code and documentation are licensed under the [MIT License](LICENSE).
Third-party datasets retain their original terms.

This folder contains the data and the code that produce every data-based table
and figure in the paper. Running `python code/scripts/run_all.py` from this
folder regenerates all of them in `output/` and ends with
a verification report, `output/verification.txt`, that lists the numbers the
paper reports next to the values just computed.

The companion Stata command `synthx` (the exact synthetic control estimator for
general use, with a separate solver implementation) is distributed separately.
When its folder `synthx_package` sits next to this one, the verification report also
compares the donor weights, losses and predictor weights with the bridge's
output; otherwise that section is skipped with a note.

## Requirements

Python 3.12 or later with numpy, scipy, cvxpy (with the CLARABEL solver, which
`pip install cvxpy` includes) and matplotlib. `requirements.txt` pins the
versions used.

## Scripts

Script names describe their role: `compute_` scripts calculate weights and
related results, `plot_` scripts generate figures, and `verify_results.py`
checks the results against the paper. `pd` means positive definite. Calculation
scripts cover both California and West Germany, except
`compute_california_leakage_free_weights.py`, which covers California only.
The three predictor-weight scripts also process the leakage-free California
case.

`run_all.py` runs these scripts in order:

1. `compute_diagonal_donor_weights.py`
2. `plot_california.py`
3. `plot_germany.py`
4. `compute_pd_donor_weights.py`
5. `plot_diagonal_vs_pd.py`
6. `compute_california_leakage_free_weights.py`
7. `compute_pd_predictor_logdet.py`
8. `compute_pd_predictor_analytic_center.py`
9. `compute_diagonal_predictor_weights.py`
10. `verify_results.py`

## Data

* `data/smoking_data.csv`: the Proposition 99 panel of Abadie, Diamond, and
  Hainmueller (2010), 39 states, 1970-2000 (as distributed with `Synth`).
* `data/german_reunification.csv`: the reunification panel of Abadie, Diamond,
  and Hainmueller (2015), 17 OECD countries, 1960-2003.
